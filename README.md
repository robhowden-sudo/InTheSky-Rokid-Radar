# In The Sky: Rokid Radar HUD

Prototype Android companion + glasses HUD split from the desktop **In The Sky** project.

## What is included

- `phone/` — Android companion app. Uses phone GPS, downloads OpenSky aircraft states, calculates exact range/bearing, filters contacts, and sends compact JSON over Classic Bluetooth.
- `glasses/` — Android glasses app. Receives JSON and renders a black/green full-screen radar HUD with animated sweep, rings, aircraft symbols, range, connection state, contact count and nearest-contact summary.
- Radar range is adjustable on the phone from **1 to 200 miles**.
- No weather, clock, launches, maps, tabs or other desktop pages are included.

## Important prototype transport choice

This first build deliberately uses Android's standard Classic Bluetooth RFCOMM API. Rokid's current SDK also supports Classic Bluetooth text messaging; using standard RFCOMM keeps this prototype independent of Rokid SDK initialization/authentication and makes the data protocol easy to test. If Glass3 firmware blocks third-party RFCOMM server sockets, replace the two transport classes with Rokid SDK messaging while keeping the same JSON protocol and radar code.

## Build requirements

- Android Studio
- JDK 17
- Android SDK 34

Open this folder as an Android Studio project. Let Gradle sync, then build both application modules:

- `phone` -> `phone-debug.apk`
- `glasses` -> `glasses-debug.apk`

Typical command once a Gradle wrapper is generated by Android Studio:

```bash
./gradlew :phone:assembleDebug :glasses:assembleDebug
```

APK locations:

```text
phone/build/outputs/apk/debug/phone-debug.apk
glasses/build/outputs/apk/debug/glasses-debug.apk
```

## First test

1. Install the `glasses` APK on the Rokid glasses and launch it. It should show the radar and `WAITING FOR PHONE`.
2. Pair the glasses with the Android phone using Android Bluetooth settings.
3. Install and run the `phone` APK.
4. Grant Location and Bluetooth permissions.
5. Tap **CONNECT ROKID GLASSES** and select the paired glasses.
6. The phone should show `LIVE • GLASSES CONNECTED`, and the HUD should begin plotting aircraft after the first OpenSky update.

## Notes

OpenSky's anonymous endpoint may rate-limit or occasionally reject large requests. Authentication support can be added later. The 200-mile setting is supported by the app, but very large ranges naturally mean more data and a wider OpenSky query.

This is version 0.1.0 and has not been hardware-tested on the user's Rokid glasses from this environment.

## Cloud APK build with GitHub Actions

This project includes `.github/workflows/build-apks.yml`.

After the project is uploaded to a GitHub repository, open **Actions** and select **Build In The Sky Radar APKs**. The workflow also runs automatically after pushes to `main` or `master`.

When the build succeeds, download these artifacts from the workflow run:

- `InTheSkyRadarPhone-APK` containing `InTheSkyRadarPhone-debug.apk`
- `InTheSkyRadarGlasses-APK` containing `InTheSkyRadarGlasses-debug.apk`

The debug APKs are automatically signed with Android's debug signing key and are suitable for initial sideloading/testing. A release signing configuration can be added after the phone-to-glasses transport is verified on real Rokid hardware.
